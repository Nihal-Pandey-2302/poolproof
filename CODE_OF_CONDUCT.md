# Code of conduct

poolproof follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and assume good faith. Criticize code, results and ideas, not
people. Pooler maintainers are guests here: a failing scenario is a report about
software, never about the people who wrote it.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub private
vulnerability reporting (the repository's **Security** tab, then **Report a
vulnerability**), and say in the title that it is a conduct report. Reports are kept
confidential. The maintainer decides on consequences as described in the Contributor
Covenant's enforcement guidelines.
