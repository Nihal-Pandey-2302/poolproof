# Verdicts CI compares loosely: "<target> <scenario> <mode>", one pair per line. Only
# that exact pair; the same scenario on other targets is compared as usual. The mode
# says what may change (.github/compare-verdicts.sh):
#   verdict  PASS and FAIL (any kind) match each other; ERROR, SKIP or a missing
#            result still fail the comparison
#   kind     a FAIL matches a FAIL of any kind; anything else must match exactly
#   reached  as the committed result (PASS, or a FAIL of any kind), and a SKIP "passed,
#            but ..." (the evidence showed the clients never shared a server
#            connection, so the run didn't count) matches it too
# CI fails on a line without a mode, a `kind` line whose committed result isn't FAIL, a
# `reached` line whose committed result isn't PASS or FAIL, a `verdict` line committed
# as ERROR or SKIP, and a pair no results/*.json has. Remove a line once the scenario
# has repeat or the cause is fixed.
